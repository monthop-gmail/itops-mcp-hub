MCP endpoints

PathRoleTools
/mcp/it/sse it และ admin Zabbix read + MeshCentral inventory
/mcp/admin/sse admin เท่านั้น ชุดเดียวกัน + meshcentral_run_shell
/mcp/it/mcp Streamable HTTP (transport ใหม่ของ MCP)

ChatGPT / Grok / Gemini: เปิด /oauth/setup เพื่อคัดลอก Client ID แล้วเชื่อม URL /mcp/it/mcp แบบ OAuth — ครั้งแรกจะเปิดหน้าให้วาง IT_TOKEN

ไคลเอนต์ที่ใส่เฮดเดอร์เองใช้ Authorization: Bearer <IT_TOKEN|ADMIN_TOKEN> ได้เช่นกัน

LAN services

Zabbix UI และ MeshCentral ไม่เปิดออกอินเทอร์เน็ตผ่านเกตเวย์นี้ — ใช้พอร์ต LAN/VPN ที่กำหนดใน .env แล้วล็อกอินที่แอปเอง

  • Zabbix web: พอร์ต ZABBIX_WEB_LAN_PORT (ค่าเริ่ม 9443)
  • MeshCentral: พอร์ต MESHCENTRAL_HTTPS_PORT / เอเจนต์ MESHCENTRAL_AGENT_PORT

อย่าใส่โทเคนลงหน้านี้ และอย่าเปิด /mcp/admin ให้บัญชี IT
