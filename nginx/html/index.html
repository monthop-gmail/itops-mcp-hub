MCP endpoints

PathRoleTools
/mcp/it/mcp it และ admin Zabbix read + MeshCentral inventory + ZKTime + pstack + RAG เอกสาร
/mcp/admin/mcp admin เท่านั้น ชุดเดียวกัน + meshcentral_run_shell + host_* เมื่อเปิด
/mcp/accounting/mcp accounting เท่านั้น Express / Allinone / Odoo อ่านอย่างเดียว + RAG เอกสาร

ใช้ Streamable HTTP ที่ลงท้าย /mcp — ChatGPT / Grok / Gemini / Cursor ไม่ต้องต่อ /sse

หน้า PDF ที่ pdftotext ว่างเข้าคิว OCR บนคลังเอกสาร — ต้อง approve ก่อนบันทึกข้อความ และค่าเริ่มต้นไม่ส่งภาพออกจากไซต์

host_* อ่านไฟล์ใต้โฟลเดอร์ที่เมานต์เข้าเกตเวย์ — เฉพาะแอดมิน และค่าเริ่ม HOST_ENABLED=false จึงไม่โผล่ในรายการเครื่องมือ ไม่ใช่ Desktop Commander และยังไม่มีเชลล์บนโฮสต์

ChatGPT / Grok / Gemini: เปิด /oauth/setup เพื่อคัดลอก Client ID แล้วเชื่อม URL /mcp/it/mcp (งาน IT) หรือ /mcp/accounting/mcp (สมุด Express / Allinone / Odoo) แบบ OAuth — ครั้งแรกจะเปิดหน้าให้วางโทเคนของบทบาทนั้น

ไคลเอนต์ที่ใส่เฮดเดอร์เองใช้ Authorization: Bearer <IT_TOKEN|ADMIN_TOKEN|ACCOUNTING_TOKEN> ได้เช่นกัน

/mcp/it/sse และ /mcp/admin/sse ยังเปิดอยู่สำหรับ Claude Desktop รุ่นเก่า ที่พูด SSE อย่างเดียว — ไม่ใช่เส้นหลัก

LAN services

Zabbix UI และ MeshCentral ไม่เปิดออกอินเทอร์เน็ตผ่านเกตเวย์นี้ — ใช้พอร์ต LAN/VPN ที่กำหนดใน .env แล้วล็อกอินที่แอปเอง

  • Zabbix web: พอร์ต ZABBIX_WEB_LAN_PORT (ค่าเริ่ม 9443)
  • MeshCentral: พอร์ต MESHCENTRAL_HTTPS_PORT / เอเจนต์ MESHCENTRAL_AGENT_PORT

อย่าใส่โทเคนลงหน้านี้ — โทเคน IT/admin ห้ามใช้กับสมุดบัญชี และโทเคนบัญชีห้ามใช้กับเส้น IT
